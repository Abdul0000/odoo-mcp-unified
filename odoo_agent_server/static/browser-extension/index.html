o Odoo MCP Browser extension

Use your logged-in Chrome.

Connect your browser to MCP for general website tasks. Cookies and passwords stay in Chrome.

  1. Download the Chrome extension ZIP and extract it.
  2. Open chrome://extensions, enable Developer mode, choose Load unpacked and select the extracted folder.
  3. Generate your fixed browser pairing code below. Paste the server URL and code into the extension popup.
  4. Click Connect / apply in the extension to grant website access. Enable form actions when you want the agent to operate the UI.
